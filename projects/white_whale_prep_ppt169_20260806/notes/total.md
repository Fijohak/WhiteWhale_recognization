# 01_封面

大家好，今天汇报中华白海豚个体识别项目的前期准备与后续方向。本周完成了数据盘点与索引，并基于数据现状确定了两个核心技术方向——跨物种迁移学习和散图分拣利用。汇报主线是：先看数据长什么样，再看数据特点如何决定技术路线。

# 02_本周进展

本周完成了四件事。第一，数据盘点：全量扫描了 01 和 03 两个调查批次，为两千八百六十三张图片建立索引，并做了精确重复检测。第二，标签体系：解析了评分区间与个体分组的语义，把数据分成 labeled、loose_known、ignored 三级，并引入 candidate-label 弱监督的概念。第三，文档整合：把数据语义、假设清单和待办事项全部写入文档。第四，也是最关键的一步——跨物种迁移学习方案成文，明确了四组对照实验的设计。这四项工作为后续技术路线提供了完整依据。

# 03_数据规模

先看整体规模。两个调查批次共两千八百六十三张照片，01 批次八百一十八张，03 批次两千零四十五张。标签分布上，43 个已分组个体覆盖一百九十九张照片，207 张 70 到 79 分的散图归属待确认，其余两千四百五十七张暂不用于训练。个体层面，单图个体 15 个，多图个体 28 个，个体照片最多 27 张；全部图片可读，精确重复只有一组两张。需要说明，个体数是按调查内分组编号统计的，跨调查同名编号未合并。

# 04_数据分布

这三张图是实际扫描的统计结果。标签状态分布显示，大多数图片未标注，可标注图片集中在 70 分以上。调查批次分布可以看到两个批次的体量对比。评分区间分布呈金字塔结构：70 到 79 分是最大的候选池，80 分以上是质量最好的标注来源，50 分以下和未知区间基本不可用。这些分布直接决定训练数据的选择策略。

---

# 05_数据特点决定技术方向

数据有四个关键特点，每个特点都指向明确的技术应对。第一，极端少样本：43 个个体各只有一张照片，模型无法从零训练，所以必须用迁移学习——外部鲸豚数据预训练加本地微调。第二，207 张散图归属未确认：可以通过人工分拣扩充标签，分拣前先作为候选标签做弱监督。第三，背鳍有左右两面，必须记录朝向、左右侧分别比较。第四，同一天两群、跨调查未核验，所以只在调查内做比较，跨调查仅作候选。由此确定两个技术方向：迁移学习和散图分拣利用。

---

# 06_散图利用方案

散图不是负担，是标签扩充池。有两条利用路径。路径 A 是人工分拣：01 批次 59 张、03 批次 148 张，分拣到对应个体文件夹后更新清单，个体标签直接扩充，缓解 one-shot 问题。路径 B 是 candidate-label 弱监督：分拣前散图就可以参与训练，但约束是只能作为同调查、同评分区间内的候选集合信息，不能当作个体标签。分拣一张，可用训练样本就加一张；207 张全部分拣完成后，个体样本量最多可以提升一倍以上。

---

# 07_迁移学习方案

迁移学习是解决少样本的关键，我们设计了四组对照实验。A 是基线，用 ImageNet 或 DINOv2 这类通用预训练模型加本地数据；B 是鲸豚监督迁移，用 Happywhale 的监督预训练加本地；C 是自监督鲸豚迁移；D 是多源鲸豚，把 Happywhale、NDD20、NOAA、Beluga 全部用上。判定标准：如果 C 或 B 优于 A，说明外部鲸豚数据有价值；如果 C 低于 B，说明存在负迁移，改用多源或自监督。执行顺序是 A 到 B 到 D 再到 C。核心判断是：我们迁移的是通用鲸豚背鳍表示，而不是某一种源物种的个体分类规则。

---

# 08_迁移学习的数据源

外部数据源分四类。Happywhale 是最大的一组，五万一千张、一万五千六百个体、三十个物种；NDD20 四千四百张，本身就是背鳍识别数据，还有分割标注；NOAA 宽吻海豚数据有 188 个体，背鳍形态最接近我们的场景；Beluga ID 五千九百张，基于疤痕和纹理识别，正好覆盖我们目标物种依赖的纹理线索。最大风险是负迁移：源域靠背鳍轮廓、目标域靠斑点纹理，直接分类迁移可能让模型忽略纹理，所以要用消融实验验证。执行顺序按规模从小到大：先 NDD20、NOAA、Beluga 跑通流程，再上 Happywhale 和多源融合。

---

# 09_技术路线总览

整体技术路线是完整的闭环。第一步背鳍裁剪和朝向标注；第二步用预训练模型提取特征并做 L2 归一化；第三步余弦相似度加 Faiss 做 Top-K 检索；第四步 HDBSCAN 候选聚类，允许噪声；第五步人工核验候选簇；第六步高可信结果生成伪标签；第七步度量学习重新提取特征；第八步建成可持续更新的个体数据库。系统输出三类结果：Top-K 候选、未知个体标记、需人工核验。核验结果回流微调模型，形成闭环迭代。

---

# 10_阶段规划

项目分七个阶段。阶段 0 语义确认和阶段 1 数据索引已经完成，对应本周的工作。阶段 2 Pilot Set 与最小基线正在进行，包括选择试点数据、基线特征提取、Top-K 检索、候选聚类、拼图生成和基线诊断六步。阶段 3 人工基准集、阶段 4 自监督与轮廓特征、阶段 5 伪标签与度量学习、阶段 6 自动化系统依次推进。阶段 0 到 1 的交付物是索引四件套：数据清单、统计文件、目录树和异常文件表，全部可追溯、可重跑。
