# 外部数据补充与数据纯净性规则

更新日期：2026-08-29

## 结论

当前原图盘按“项目已授权”处理，可用于本项目内部重建、训练和评测。这个授权不自动延伸到外部数据源。

外部数据可以用于隔离的预训练、域适配或独立外部诊断，但只有同时满足“同一只个体、可信拍摄日期、可追溯来源、用途授权”的资料，才可以构成外部跨时正样本。外部样本不得直接并入内部测试集，也不得用其他鲸豚物种的同体关系替代中华白海豚的项目内跨年结论。

因此，向原数据技术人员索取经核验的跨年同体照片，仍是验证本项目跨年识别能力的首选路径。缺少这类资料时，当前结果只能表述为“短时间间隔、批次内、跨连拍串识别”，不能外推为跨年能力。

## 可用范围

| 数据条件 | 允许用途 | 禁止用途 |
|---|---|---|
| 中华白海豚；同体 ID 与拍摄日期可信；授权明确 | 隔离预训练；独立外部跨时测试；经去重后加入训练 | 与内部测试集混算；未核验即当项目跨年真值 |
| 中华白海豚；有图但无可信日期或同体 ID | 检测器、裁剪器、无监督域适配 | 构造正样本；报告跨年指标 |
| 其他鲸豚；有个体 ID | 通用表征预训练、代码流程验证 | 作为中华白海豚准确率或跨年能力证据 |
| 来源、许可或身份关系不清 | 不接入 | 训练、阈值标定、评测、发布 |

## 已核对的候选来源

- [Happywhale - Whale and Dolphin Identification](https://www.kaggle.com/competitions/happy-whale-and-dolphin/data)：适合作为其他鲸豚的外部表征预训练候选。下载前必须登录并接受当期竞赛规则；竞赛标签不能自动证明有可用的拍摄日期，也不能替代本项目中华白海豚跨年真值。
- [PhotoID-Image-Process v1.0.1](https://zenodo.org/records/15870375)：Zenodo 条目说明其 YOLO 模型训练于中华白海豚背鳍，软件条目标为 Apache-2.0。它首先是工具和模型发布，不等于其中所有图片均可作为本项目训练数据；必须逐项检查压缩包内容、图片权利和模型来源后才能接入。
- [Fin whale sighting histories, 1987–2018](https://zenodo.org/records/7672262)：条目包含 932 只长须鲸的长期目击历史，许可为 CC0，但发布文件主要是 CSV/README，不是可直接训练视觉识别的照片。可参考时间切分和长期重遇评估设计，不能作为本项目图像正样本。
- [Flukebook / Wildbook 文档](https://wildbook.docs.wildme.org/getting-started-with-wildbook.html)：支持数据隔离与协作权限。此类平台中的照片应由数据拥有者显式共享，不能把“平台可访问”视为可批量下载或可再训练授权。

以上核对只确认公开页面在 2026-08-29 可访问；正式接入前仍需保存下载当日的许可/条款快照。

## 接入门禁

每个外部数据包必须单独存放，并建立不可变来源清单，至少记录：

- `source_dataset`、原始 URL/DOI、获取日期、提供者；
- 许可名称、条款快照、允许的训练/发布范围；
- 物种、原始个体 ID、拍摄日期及日期证据；
- 文件 SHA-256、感知哈希、原文件名；
- `source_dataset + original_identity_id` 组成的内部身份命名空间；
- 允许用途：`pretrain_only`、`train_only` 或 `external_eval_only`。

接入前执行以下检查：

1. 用 SHA-256 和感知哈希检查内部数据、外部训练集、外部测试集之间的重复和近重复图。
2. 同一身份按时间/事件分组，连拍串不得跨 train/validation/test。
3. 外部测试集保持只读，阈值和模型选择不得读取其标签结果。
4. 内部指标与外部指标分别报告，不合并分母；同时报告物种、来源和时间跨度。
5. 任何身份或日期冲突都进入人工复核，不靠文件名猜测。
6. 模型发布前复核许可是否允许权重再分发；不允许时只保留内部使用记录。

## 当前执行决定

- 先完成项目内完整 manifest 的同串剔除、严格产物重建和短间隔评测。
- 不自动下载或混入任何外部照片。
- 若获得技术人员提供的跨年同体资料，单独建立 `external_eval_only` 基准，先去重、再盲测。
- 外部数据只在通过上述门禁后启动新的实验版本，绝不回写当前内部基准真值。
