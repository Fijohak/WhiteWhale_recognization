# P2 特征与数学原理：一个向量，怎么就算"像"

> 面向算法/工程人员。本文拆开"图片 → 向量 → 相似度"这条链，讲清楚 ArcFace 和 triplet 两个损失函数到底在干什么。

## 一、backbone：图片变成向量

入口是一个 ViT（Vision Transformer），用的预训练模型叫 **MegaDescriptor-T-224**：

- 输入：224×224 的背鳍裁剪图；
- 输出：一个 **768 维向量**，就是这个图的 **embedding**。

代码位置：`src/whitewhale/reid/embedding.py:75-87`（`make_backbone`，从 timm 的 hf-hub 加载 `BVRA/MegaDescriptor-T-224`）。

> 为什么选它？因为它是在**大量野生动物数据**上预训练过的，天生就懂"动物表皮纹理、轮廓"这类通用特征，比从零开始训强得多。这一步叫"迁移学习"——借别人的预训练当起点。

## 二、L2 归一化：让一切退化成"方向"

拿到 768 维向量后，做一步关键操作——**L2 归一化**，让每个向量长度都压成 1，全部落到单位球面上。

```python
# 代码里到处都在做这件事（embedding.py:151-154 等）
emb = emb / np.linalg.norm(emb, axis=1, keepdims=True)
```

归一化之后，两个向量的**余弦相似度 = 点积**：

```
cos(a, b) = a·b / (|a|·|b|) = a·b        （|a|=|b|=1）
```

值域 [-1, 1]：`1` = 方向一致（最像），`0` = 垂直，`-1` = 完全相反。

**这是全文唯一的"距离"定义。** 后面所有的分数、阈值、检索、聚类，全部建筑在这个 cosine 上。先记住这一点。

## 三、ArcFace：逼着模型"留出余量"

ArcFace 是训练分类头时用的 loss。它的想法一句话：

> 分类时，别只要求"正确类的分数最高"，而是要求它**比第二名高出一个固定角度余量**。

数学上，ArcFace 把 softmax 里的 logit 改写成：

```
logit_i = s · cos(θ_i + m)    （仅对正确类别 i；其他类别仍是 s·cos(θ_j)）
```

- `θ_i`：特征向量和"类别 i 的权重向量"之间的夹角；
- `m = 0.3`（margin，角度余量）：给正确类别额外加 0.3 弧度的门槛；
- `s = 32`（scale）：把余弦值放大，让 softmax 的梯度别太软。

代码位置：`src/whitewhale/reid/embedding.py:39-56`（`ArcFaceHead`，`s=32, m=0.3`）。

**直觉**：加了 margin，模型不能"勉强对上"就算赢，必须把正确类的夹角 `θ` 压得更小，才能抵消那个 `+m`。于是类内（同一只海豚）被**压得更紧凑**——这正是度量学习要的。

## 四、Triplet loss：直接拉近推远

ArcFace 通过分类间接优化距离；Triplet 则**直接**操作距离。

Triplet 每次取三张图：锚（anchor）、正样本（positive，同一只）、负样本（negative，不同只），目标：

```
L = relu( d(anchor, positive) − d(anchor, negative) + margin )
```

- `d` 是距离（这里用 `1 − cos`，代码里 `d = 1 - cos`）；
- `margin = 0.3`：要求"正样本比负样本近至少 0.3"，否则就有损失。

代码位置：`src/whitewhale/reid/training.py:173-189`（`triplet_hn_loss`）。

**为什么用"hard negative"**：普通 triplet 随机抽负样本，太简单——两张不同海豚本来就不像，`d(an)` 很大，loss 直接是 0，梯度为零，学不到东西。**Hard negative mining** 是每个 anchor 在 batch 里挑"最像的那只不同海豚"当负样本，专攻难区分的边界。本项目是"batch 内动态挖掘"（每个 anchor 取 batch 内跨群 cosine 最高者）。

## 五、两把"力"怎么合起来

最终 loss：

```
L = ArcFace_CE + λ · triplet        （λ = 0.2，代码里 lambda_hn）
```

代码位置：`src/whitewhale/reid/training.py:192-211`（`train_one_epoch_hn`）。

- ArcFace 负责"把正确类压紧"（类内紧凑）；
- Triplet 负责"把最难分的负样本推开"（类间分离）；
- `λ=0.2` 是权重，triplet 只是辅助——主裁判还是 ArcFace。

## 六、预处理的"一致性"红线

训练和推理的预处理**必须完全一致**，否则特征不在同一个分布里，比不了：

- 训练（`training.py:73-88`）：`RandomResizedCrop(224) + 旋转 + 色彩抖动`（增强）
- 推理/特征提取（`embedding.py:249-259`）：`Resize(256) → CenterCrop(224)`

注意那个 `Resize(256)+CenterCrop(224)`：这是 MegaDescriptor 的官方输入规格，微调特征提取器 `MegaDescriptorMetricAdapter` 也严格照做，保证查询图和历史库图同分布。

> **一句话**：backbone 给"长相"，L2 给"方向"，ArcFace 管"类内压紧"，triplet 管"类间推开"，cosine 管"像不像"。这就是全部数学骨架。
