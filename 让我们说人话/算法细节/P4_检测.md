# P4 检测：先找到背鳍，再谈认海豚

> 面向算法/工程人员。本文讲上游的 YOLO 检测器，以及那个"非均匀扩展裁剪"为什么这么设计。

## 一、为什么需要检测

照片里海豚不一定在画面中央，可能只占一角，周围是海水、天空、别的海豚。直接把整图喂给特征模型，会引入大量无关背景。

所以整条链的第一步是：**用检测器把背鳍框出来，裁掉背景**。

用的是 **YOLOv8n**（最轻量的一档），配置在 `configs/detector.yaml`：

- `imgsz: 1024`（输入尺寸，因为背鳍要保留细节）
- `conf: 0.25`（推理置信度阈值）
- 权重 `models/detectors/yolov8n_dorsalfin.pt`

## 二、非均匀扩展裁剪：背鳍上下不一样

检测出框后，不是直接用框，而是**非对称地往外扩一圈**再裁。代码在 `src/whitewhale/detection/detector.py:24-42`（`expand_box`）：

```python
pad_x   = 0.30 × 框宽     # 左右各扩 30%
pad_up  = 0.15 × 框高     # 上方扩 15%
pad_down= 0.60 × 框高     # 下方扩 60%
```

**为什么上下不对称**——这是背鳍的解剖特点决定的：

- **下方连着身体**，判别信息（背鳍与背部的过渡、身体轮廓）在下边，所以要**多留**（60%）；
- **上方是"自由边"**（free edge），背鳍的缺口、凹陷这些最关键的个体特征就在这条边上，但**再多留也还是天空**，所以只留 15%；
- 左右留 30%，容纳背鳍的自然倾斜。

扩完还要 **clamp 到图内 + 尺寸上限**（边长 ≤ 0.9×min(宽,高)，面积 ≤ 60% 原图），防止框扩得过大把背景又吃回来。

## 三、未检出怎么办：回退中心裁剪

如果 YOLO 没框到（背鳍太小、太糊、角度太怪），**不能空手而归**。回退策略是**中心 0.45 窗裁剪**，并在清单里打 `fallback=True` 标记。

代码位置：`detector.py:96-102`。

```python
side = int(min(w, h) * 0.45)      # 取图中心 45% 的正方形
box = [left, top, side, side]
fallback = True                    # 可追溯
```

> **为什么回退中心裁剪**：历史早前（没有检测器时）就是这么干的，0.45 是当时的经验值。保留它，一是"有兜底总比没裁剪强"，二是让结果可追溯——你知道这张图是"没检测到、退化到中心裁剪"的。

## 四、检测到底值不值？（E1/E2 的结论）

这个问题是**分场景**的，两个实验给了干净答案：

**特写图（招牌照）**：背鳍本来就占满画面、基本居中，检测裁剪 ≈ 中心裁剪 ≈ 整图，**三者打平**（R@1 都在 0.31 附近，见 E1）。检测在特写图上没有增量。

**散图（背鳍不居中）**：检测裁剪**显著更好**。E2 里"散图 → 同批已确认个体"的 Top-1 分数，检测裁剪中位 **0.866 vs 中心 0.812**，Wilcoxon 配对检验 p=3.4e-16，极显著。

**结论一句话**：检测器的价值不在"特写图"，在"背鳍不在正中间的散图"——而散图恰恰是这个项目要自动归档的主角。所以全链路统一用"检测裁剪"。

## 五、检测器的训练（了解即可）

检测器本身也要训练（`scripts/train_detector.py`），数据是 SAM 自动掩码辅助预标注 + 人工抽查（E1：167 张训练，mAP50=0.635）。但**这是上游独立一环，日常跑流程用的是已训练好的权重**，一般不用重训。

> **一句话**：检测 = "先定位背鳍"；非均匀扩展 = "按背鳍的解剖结构留边"；回退 = "没检测到也有兜底"。它的存在，让下游特征模型只盯着背鳍，而不是盯着一整片海。
